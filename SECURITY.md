# Security Policy

## Supported Versions

Only the latest release version of FreshstartCI receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1.0 | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability in FreshstartCI, please report it via GitHub Private Vulnerability Reporting on this repository, or email eshaanaggarwal@gmail.com.

Please include:
- A description of the vulnerability and potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.

### Response Time
- **Initial Acknowledgment:** Within 48 hours.
- **Status Update & Resolution Target:** Within 7 business days.

Please do not report security vulnerabilities through public GitHub issues.
